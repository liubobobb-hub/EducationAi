# LearnFun with Benny!

An interactive educational website designed to help young children learn English and Math through fun activities featuring Benny the Bunny.

## 🌟 Overview

LearnFun is a child-friendly educational platform that offers various learning activities in two main subject areas: English and Mathematics. The website features an engaging mascot, Benny the Bunny, who guides children through different educational games and activities.

## 📚 Features

### English Activities
- **Alphabet Fun**: Learn the ABCs through interactive exercises
- **Word Games**: Build vocabulary with engaging word activities
- **Story Time**: Enjoy interactive stories with Benny
- **Phonics Play**: Practice letter sounds and phonics skills

### Math Activities
- **Counting Corner**: Learn to count with fun visual aids
- **Shape Shifters**: Explore and identify different shapes
- **Simple Sums**: Introduction to basic addition
- **Number Puzzles**: Solve engaging mathematical puzzles

## 🖥️ Technical Information

- Built with HTML, CSS, and JavaScript
- Mobile-responsive design
- Kid-friendly interface with colorful themes
- No external dependencies required (except Google Fonts)

## 📁 Project Structure

```
├── math.html              # Math subject landing page

├── style.css              # Global styles
├── *_activity.html        # Individual activity pages

└── sounds/                # Audio files for activities
```

## 🚀 Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Navigate through the website by clicking on subject areas and activities
