# Educational Platform for Young Learners

## Project Purpose

This project aims to provide an educational platform for children aged 1 to 5 years old. It focuses on foundational skills in English, basic arithmetic, and literacy.

## Project Structure

The educational content is organized into the following main categories:

-   **/english**: Contains modules for English language learning.
    -   **/1-2_years**: Activities designed for toddlers, focusing on topics such as colors and animal names.
    -   **/3-5_years**: Activities tailored for preschoolers, covering areas like alphabet sounds and simple stories.
-   **/math**: Contains modules for developing basic arithmetic skills.
    -   **/counting**: Activities focused on learning to count.
    -   **/shapes**: Activities designed to teach basic geometric shapes.
-   **/literacy**: Contains modules for building early literacy skills.
    -   **/alphabet**: Activities for learning the letters of the alphabet.
    -   **/phonics**: Activities focused on understanding phonics and letter sounds.
